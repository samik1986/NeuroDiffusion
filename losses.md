# NeuroDiffusion Loss Functions

The training of the NeuroDiffusion pipeline relies on a composite objective function that balances topological, morphological, and heuristic validity. The losses are primarily unified in `utils/loss_functions.py` under the `NeuroDiffusionLoss` module, with a separate discriminator-style loss for the Heuristic Evaluator.

---

## 1. Edge Loss (Topology)
**Type:** Binary Cross Entropy with Logits (`nn.BCEWithLogitsLoss`)
**Component:** Backward Diffusion Model
**Weight:** `1.0` (default)

**Description:**
The Backward Diffusion Model functions as a hybrid EGNN and Graph Transformer that attempts to predict which disjoint sub-trees should be connected. For a given set of candidate edges, it outputs a logit. The Edge Loss computes the binary cross-entropy between these predicted logits and the ground truth labels ($1$ if the edge exists in the uncorrupted graph, $0$ otherwise). 

## 2. Coordinate Loss (Morphology)
**Type:** Masked Mean Squared Error (`nn.MSELoss(reduction='none')`)
**Component:** Sequence Generator (Continuous DDPM)
**Weight:** `10.0` (default)

**Description:**
The Sequence Generator is a continuous diffusion model tasked with predicting the 3D coordinates (or the noise added to them) of a neuronal path sequence. 
Because neuronal branches have variable lengths, the sequences are padded. The Coordinate Loss computes the MSE between the predicted coordinates and the true coordinates, but strictly applies a boolean `coord_mask` to ignore the padded regions. The final value is the mean error across all valid coordinate positions.

## 3. Node Type Loss (Structure)
**Type:** Masked Cross Entropy (`nn.CrossEntropyLoss(reduction='none')`)
**Component:** Sequence Generator
**Weight:** `0.5` (default)

**Description:**
Alongside coordinates, the sequence generator must predict the structural intent of every node in the sequence. These are categorized into three classes:
- `0`: Continue (standard path node)
- `1`: Branch (node where a bifurcation occurs)
- `2`: Terminate (end of the branch)

This is optimized using a standard Cross-Entropy loss over the predicted logits. Similar to the coordinate loss, a `type_mask` is applied so that padded tokens do not contribute to the loss calculation.

---

## 4. Heuristic Evaluator Loss (Discriminator)
**Type:** Binary Cross Entropy with Logits (`nn.BCEWithLogitsLoss`)
**Component:** Validity Heuristic Evaluator
**Location:** `trainers/heuristic_trainer.py`

**Description:**
The Heuristic Evaluator acts as a binary classifier (akin to a GAN discriminator) to score the biological validity of a generated sequence. It is trained on a balanced batch containing:
- **Valid Samples** (label `1`): Ground-truth paths connecting `Context 1` and `Context 2`.
- **Fake Samples** (label `0`): Paths generated by the Sequence Generator or heavily corrupted noise paths.

The model is optimized to minimize the BCE loss between its validity logits and these binary labels, learning to reject structurally impossible neuron bridges.

---

## 5. Zero-Shot Inference Cost Formulation
**Type:** Composite Energy Function  
**Component:** `ZeroShotEvaluator` (Inference Pipeline)  
**Location:** `inference/evaluator.py`

**Description:**
During live sliding-window inference, candidate connections between disconnected endpoints are evaluated without any ground-truth labels. The evaluator computes a composite cost $C$ for a generated path $X$:

$$ C = \alpha \cdot \text{Cost}_A(X) + \beta \cdot \text{Cost}_B(X) $$

- **$\text{Cost}_A$ (Neural Gap):** The output of the trained Validity Heuristic Evaluator, which predicts the scale-invariant MSE structural gap to an ideal biological path. Lower is better.
- **$\text{Cost}_B$ (Intensity Path Integral):** Evaluated over the raw image volume. For every step along the generated path $X$, the cost is minimized if the path lies on a high-intensity ridgeline (`Vesselness`) and the step direction aligns closely with the biological structure's orientation (`Tangent`).
$$ \text{Cost}_B(X) = - \frac{10.0}{|X|} \sum_{i} \text{Vesselness}(x_i) \cdot |\langle \text{Tangent}(x_i), \text{StepDir}(x_i) \rangle| $$

Paths with a combined cost $C < 0$ are accepted and securely stitched into the biological graph's topology.
